# 二段跳移動向量校準（X + 間隔 + 技能 P）

## 機制
真正的二段跳 = **跳躍 X → 間隔 → 二段技能鍵 P**（不是連按兩次 X，連按易誤差）。
間隔會影響**距離**與**高度**；朝向由「最後觸發的方向鍵」決定（見 keyboard.last_dir）。

## 驗證數據（3 輪重複量測，小地圖座標系，平地，面向右）

| 間隔(s) | 距離(px) | 高度(px) | 一致性 |
|--------:|---------:|---------:|:------:|
| 0.10 | 27 | 7.3 | ✅ 範圍差 ≤1 |
| 0.14 | 28 | 8.0 | ✅ |
| 0.18 | 29 | 9.0 | ✅ |
| 0.22 | 29 | 10.0 | ✅ |
| 0.26 | 30 | 10.0 | ✅ |
| 0.30 | 31 | 10.7 | ✅ |

（每個間隔 3 輪，距離/高度範圍差皆 ≤1px，數據穩定可用）

## 規律
- **距離**隨間隔緩增：0.10→27px、0.30→31px（範圍窄，約 27-31px）
- **高度**隨間隔明顯遞增：0.10→7px、0.30→11px（**可調維度**，用間隔選跳躍高度）
- **觸發窗口寬**：0.10 即觸發（比連按兩次 X 的 0.13 門檻更寬容）

## 待補
- **速度**：minimap 僅 10Hz 取樣，跳躍 0.6s 內解析度不足（都算成 ~98px/s，不可靠）。
  要測準需更高頻取樣（視頻幀分析，或提高小地圖偵測頻率）。
- 更大間隔（0.35+）的高度上限與觸發終點尚未測。
- 「按住方向鍵 + X+P」是否加距離尚未測。

## 量測方法
`POST /calib/start {kind:jump, values:[interval], skill_key:"p"}`；
每次以左方向鍵走回最左固定起點 → 輕點右轉向 → X+P 二段跳，量小地圖黃點位移。
所有按鍵用 press(key_down→按住 60ms→key_up)，避免 tap 放開太快被遊戲漏讀。
