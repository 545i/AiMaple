# 二段跳移動向量校準（X + 間隔 + 技能 P）

## 機制
真正的二段跳 = **跳躍 X → 間隔 → 二段技能鍵 P**（不是連按兩次 X，連按易誤差）。
間隔會影響**距離**與**高度**；朝向由「最後觸發的方向鍵」決定（見 keyboard.last_dir）。

## 驗證數據（3 輪重複量測，小地圖座標系，平地，面向右）

| 間隔(s) | 距離(px) | 高度(px) | 一致性 |
|--------:|---------:|---------:|:------:|
| 0.10 | 27 | 7.3 | ✅ 範圍差 ≤1 |
| 0.14 | 28 | 8.0 | ✅ |
| 0.18 | 29 | 9.0 | ✅ |
| 0.22 | 29 | 10.0 | ✅ |
| 0.26 | 30 | 10.0 | ✅ |
| 0.30 | 31 | 10.7 | ✅ |

（每個間隔 3 輪，距離/高度範圍差皆 ≤1px，數據穩定可用）

## 規律
- **距離**隨間隔緩增：0.10→27px、0.30→31px（範圍窄，約 27-31px）
- **高度**隨間隔明顯遞增：0.10→7px、0.30→11px（**可調維度**，用間隔選跳躍高度）
- **觸發窗口寬**：0.10 即觸發（比連按兩次 X 的 0.13 門檻更寬容）

## 垂直移動向量

### 繩索 C（向上）
- 按 C 上升，最多向上 **3 層**（第一層→第四層）；施放期間再按 C 可**提前中斷**（停在較低層，不再繼續向上）。
- **冷卻 3.2 秒**。
- 實測（不中斷）：上升 **31px**（y 81→50）= 3 層，每層 ≈10px。按 C 後約 **0.5s 才開始上升**，0.3s 內升完停住。
- 中斷時機 → 上升層數（**實測結論**）：繩索 0.5s 才真正開始上升。
  - 中斷 **<0.5s 無效**（繩索繼續升滿到第 4 層，31px）
  - 中斷 **≥0.5s** → 停第 3 層（24px，減 1 層）；0.50~0.75s 全部同結果
  - 上升太快（0.3s 升 3 層），過 0.5s 門檻後中斷只能減 1 層，**無法停第 1、2 層**
  - ⇒ 繩索垂直向量只有**兩檔**：第 4 層（不中斷）或第 3 層（≥0.5s 中斷）。
    要到第 1、2 層改用下跳閉環。

### 下跳（下方向鍵 + 跳躍 X）
- 機制：**按住下方向鍵（先按穩 ~0.2s）再接跳躍 X**。若下鍵沒先按穩就跳，下跳不觸發（實測 0.05s 太快 → 0px）。
- 單次降 ~5-8px（不到一整層）。
- **閉環下跳**（借鑑 auto-maple Fall）：壓住 down + 重複跳，每跳重讀黃點，到目標層 y 停、counter 上限防卡死。實測從第三層(y57)**4 跳**回第一層(y81)。

### 測試循環（已驗證）
繩索 C 上升 → 閉環下跳回第一層 → 重複。用於循環量測繩索中斷時機等。

## 待補
- **速度**：minimap 僅 10Hz 取樣，跳躍 0.6s 內解析度不足（都算成 ~98px/s，不可靠）。
  要測準需更高頻取樣（視頻幀分析，或提高小地圖偵測頻率）。
- 更大間隔（0.35+）的高度上限與觸發終點尚未測。
- 「按住方向鍵 + X+P」是否加距離尚未測。

## 量測方法
`POST /calib/start {kind:jump, values:[interval], skill_key:"p"}`；
每次以左方向鍵走回最左固定起點 → 輕點右轉向 → X+P 二段跳，量小地圖黃點位移。
所有按鍵用 press(key_down→按住 60ms→key_up)，避免 tap 放開太快被遊戲漏讀。
